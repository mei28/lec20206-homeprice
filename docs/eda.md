# EDA

Conclusions only; the exploration lives in `notebooks/s0_data.py` (marimo, stage S0, #5).

## Questions asked

- 何を予測し、どう採点されるか
- test はどう作られたか
- train と test で何が違うか

## Findings

- 目的変数は取引価格の総額（円）。50,000〜16,000,000,000 円、中央値 3,800万円。右に長い裾を持ち、log1p をとると左右対称に近い。
- RMSLE は log1p した値の RMSE と同じ。log1p を目的変数にして L2 損失で学習すれば、指標をそのまま最小化できる。10% のずれで約 0.1、2倍と半分はどちらも 0.693。
- `価格情報区分` は2種類。成約価格情報は 2021Q1 から現れ、2025Q1 から四半期あたり約 6,600 件に増える。
- 成約価格情報の行には `用途`、`今後の利用目的`、`建ぺい率（％）`、`容積率（％）`、`取引の事情等` が一切なく、`改装` も 95% 欠損。これらの列の欠損は区分を表している。
- ㎡単価は両区分とも上がり続けている。取引価格情報のほうが㎡単価が高く、面積は小さい（2024〜2025年の中央値で、取引 102.5万円/㎡・45㎡、成約 88万円/㎡・65㎡）。区分によって取引される物件の種類が違う。
- 表記ゆれ: `最寄駅：距離（分）` は30分を超えるとレンジ表記（`30分～60分`、`1H～1H30`、`1H30～2H`、`2H～`）。`建築年` に `戦前` が21件。`面積（㎡）` に `2,000㎡以上` が1件。文字列は全角（`ＲＣ`、`３ＬＤＫ`）。
- 場所の値は test でもほぼ既知。train にない値を持つ test の行は、地区名で4件、駅名で1件、市区町村は0件。

## Train vs test distribution shift

- 時間: test は train の直後の3四半期（2025Q3〜2026Q1）。
- 価格水準: 検証期間（2025Q1〜Q2）の log1p 価格の平均は、学習期間（〜2024Q4）より 0.197 高い（約 22%）。test はさらに後ろの期間。
- 区分の構成: 成約の割合は学習期間 43%、検証期間 62%、test 67%。test の 2026Q1 は取引価格情報が 1,487 件しかなく、公表の遅れと見られる。

## Implications for validation and features

- CV は時系列 holdout（`folds/holdout_2025q1.parquet`、#4）。ランダムな KFold は未来への外挿を測れない。
- 木のモデルは学習範囲を超える価格を出せないので、時間トレンドの補正が要る（S3、#16）。
- 区分を特徴量に入れ、holdout の誤差を区分別に読む（S2、#14）。
- 表記ゆれの数値化（S2、#9）、築年数（#10）、間取りの分解（#11）、取引時期の連続値化（#12）。
- 場所はカテゴリのまま test に通用する（S2、#13）。TE（S4、#18）と座標（S6、#21 #22）で強める。
