# Glossary

Maintained by the `kaggle-journal` skill. Abbreviations and terms used in docs, Issues, and replies.
Add a row when a new term enters use. The pinned Glossary Issue's body is this file, replaced whole
(`gh issue edit <n> --body-file docs/glossary.md`).

## Task

| Term | Meaning |
|---|---|
| RMSLE | Root Mean Squared Logarithmic Error。予測と正解をそれぞれ log(1+x) にしてから RMSE を取る。本コンペの評価指標で、小さいほど良い。価格の「比率のずれ」を測る |
| 目的変数 / target | 予測する値。本コンペでは `取引価格（総額）`（円）。提出ファイルでは列名が `price` |
| Public / Private LB | 順位表。Public は test の一部で計算され期間中に見える。Private は残りで計算され、最終順位を決める |
| AI単独ベースライン | 主催者がコーディングエージェント単独で作らせた予測。順位表の `benchmark_AI.csv`（Public 0.19726） |

## Data

| Term | Meaning |
|---|---|
| 不動産取引価格情報 | 国交省が取引当事者へのアンケートで集めた取引価格。2005年から。`価格情報区分` の値の1つ |
| 成約価格情報 | レインズ（不動産流通機構）の成約情報を国交省が加工したもの。戸建とマンションのみ、2021年から。`価格情報区分` の値の1つ |
| ㎡単価 | 取引価格 ÷ 面積。物件の広さの違いを除いた価格水準 |
| 価格指数 | 四半期ごとの価格水準を基準期と比べた値。本 repo では学習データから作る（S4） |
| ヘドニック指数 | 価格を「時期」と「物件の性質（場所、区分、面積、築年数など）」で回帰し、時期の効果だけを取り出した価格指数。取引される物件の顔ぶれが変わっても動かない |
| 外挿 | 学習データの範囲の外（未来の四半期など）の値を推し量ること。木のモデルは苦手で、本 repo では価格指数を直線で延ばして補う |
| 実質価格 | 価格を価格指数で割った値。時期による価格水準の違いを除いた価格 |
| 外部データ | 配布データ以外のデータ。公開・無料・全員が同じく入手できるものに限り使える。テスト期間（2025Q3 以降）の取引データは禁止 |

## Validation

| Term | Meaning |
|---|---|
| CV | Cross Validation（交差検証）。手元で学習に使わなかったデータでスコアを測ること。本 repo では時系列 holdout 1つ |
| 時系列 holdout | 期間で切る検証。2024Q4 までで学習し、2025Q1〜Q2 で検証する（`folds/holdout_2025q1.parquet`） |
| fold -1 / fold 0 | fold ファイルの値。-1 は学習専用の期間、0 は検証期間 |
| OOF | Out-of-fold prediction。学習に使わなかった fold への予測。本 repo では検証期間（fold 0）の予測 |
| リーク | 予測時点では使えない情報（未来の値、正解）が学習や特徴量に混ざること。CV が実力より良く見える |
| early stopping | 検証データのスコアが一定回数改善しなくなったところで、木を足すのを止めること。本数を検証データで選ぶので CV がわずかに楽観的になる |
| refit | 提出用に、検証期間も含めた全期間で学習し直すこと。本 repo では holdout で選んだ本数に行数の比を掛けて使う |
| ブートストラップ | 行を重複を許して選び直し、スコアを何度も計算してばらつきを見る方法。2つの run の差の 95% の範囲が 0 をまたげば、差は偶然の範囲と読む |
| 系統的なずれ（bias） | 誤差の平均。0 から離れていると、予測が全体として高め・低めに偏っている。二乗誤差の平均 = ずれの二乗 + ばらつき |

## Models and experiments

| Term | Meaning |
|---|---|
| 段階（S0〜S10） | 講座の1回分。1段階が1本の marimo ノートブックと1回の提出に対応する（`docs/roadmap.md`） |
| GBDT | 勾配ブースティング決定木。LightGBM など。表データの定番 |
| MLP | 多層パーセプトロン。全結合層を重ねた素朴なニューラルネット |
| TE | Target Encoding。カテゴリごとの目的変数の平均を特徴量にする方法。fold の外で計算するとリークする |
| out-of-fold（TE） | 学習に使う行の TE を、その行を含まない残りの fold から計算すること。自分の答えが特徴量に入らない |
| 平滑化（TE） | 行の少ないグループの平均を全体の平均に寄せること。本 repo では (合計 + 20 × 全体平均) / (行数 + 20) |
| アンサンブル | 複数のモデルの予測を平均などで組み合わせること |
| run | 1回の学習の記録。`output/<ノートブック名>/<run>/` に `metrics.json` などが残る |
| 重要度（gain） | LightGBM で、その特徴量による分割が誤差をどれだけ減らしたかの合計 |
| XGBoost / CatBoost | LightGBM 以外の代表的な GBDT のライブラリ。木の育て方とカテゴリの扱いが違う |
| count encoding | カテゴリの値ごとの行数を特徴量にする方法。人気や供給量の代わりになる |
| RandomForest | 深い木を独立に多数育てて平均するモデル（バギング）。ブースティングとは間違え方が違う |
| Ridge | L2 正則化付きの線形回帰。弱いが木と違い、トレンドを直線で外挿できる |
| seed 平均 | 乱数の種（seed）だけを変えて同じモデルを何本か学習し、予測を平均すること。偶然によるぶれが減る |
| 2分割の交差検証（holdout） | holdout を四半期で2つに分け、片方で重みやメタモデルを学び、もう片方で採点すること。逆向きも行う |
| stacking | 各モデルの予測を入力にして、組み合わせ方を別のモデル（メタモデル）に学ばせるアンサンブル |
| pseudo label | モデルが test に出した予測を仮の正解として、test の行を学習データに足すこと。予測を作るモデルを教師、足して学習するモデルを生徒と呼ぶ（S11、#34） |
| 蒸留（distillation） | 強いモデル（教師）の予測を正解の代わりにして、別のモデル（生徒）に写すこと |
| 黒魔術（NN stacking） | Kaggle で、NN などの非線形モデルで行うスタッキングの俗称。手順が複雑で過学習しやすい。S12 では MLP と LightGBM のスタッキングと、その平均を試した（#35） |
| 下限（floor） | 全件に同じ値（学習期間の中央値）を出したときのスコア。モデルのスコアを読む目盛りの端 |
